What this page checks, and what it does not. It checks that required fields are filled in, dates are real dates written as YYYY-MM-DD, links are written in a valid format (https://...), and values match the allowed lists. It also flags records not verified in the last {{ site.stale_after_days }} days. It cannot tell whether a link still works or whether information is still correct. Those must be checked by a person, which is what "last verified" records.

Data checked {{ site.time | date: "%B %-d, %Y at %-I:%M %p" }} (when the site was last built).
