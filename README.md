# Paw Protection Alliance

Source for [pawprotectionalliance.org](https://pawprotectionalliance.org), built with Jekyll and published with GitHub Pages.

Paw Protection Alliance is an independent animal-welfare research and education initiative. It is not incorporated and is not a registered nonprofit.

- Content: `_articles/` (research articles), `_data/legislation.csv` (legislation tracker)
- Site settings: `_config.yml`
- Data validation for maintainers: `/data-check/`
